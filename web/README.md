# Galingo — Versión Web Beta (PWA)

Esta carpeta está destinada al despliegue web de Galingo.

## 🌐 Despliegue y Acceso:
Para compilar la versión Web PWA para publicar en Vercel, Netlify o GitHub Pages:

```bash
flutter build web --release
```

Los archivos estáticos (`index.html`, `main.dart.js`, assets y service workers PWA) se generarán en `build/web/`.
