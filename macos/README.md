# Galingo — Ejecutable Beta para macOS (.app / .zip)

Esta carpeta contiene la aplicación ejecutable nativa de **Galingo para macOS** (Apple Silicon y Mac Intel).

## 🖥 Archivos Incluidos:
- **`Galingo.app`**: Paquete ejecutable de la aplicación para macOS.
- **`Galingo-macOS-Beta.zip`**: Paquete comprimido ejecutable listo para compartir o enviar por correo/Drive.

## 🚀 Cómo Ejecutar en Mac:
1. Haz doble clic en `Galingo.app` (o descomprime `Galingo-macOS-Beta.zip` y abre `Galingo.app`).
2. Si macOS muestra el mensaje de Gatekeeper *"No se puede abrir porque proviene de un desarrollador no identificado"*:
   - Haz **clic derecho (o Control + Clic)** sobre `Galingo.app` y selecciona **Abrir**.
   - Haz clic en **Abrir** en el cuadro de diálogo de confirmación.
